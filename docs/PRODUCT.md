# Subnet City — Product Brief

**Name:** Subnet City  
**Tagline:** Build the network. Learn the logic.  
**Category:** Isometric educational networking simulator / light strategy game.

## Vision
Turn abstract networking concepts into an explorable city. Learners select network devices, arrange them on an isometric canvas, connect and configure them, simulate synthetic packet delivery, observe explanations, and complete progressively harder missions.

## Audience
IT/networking beginners, PEN-200 and cybersecurity students, junior network engineers, teachers and self-taught learners. Educational first; accuracy and intuitive cause-and-effect matter more than a realistic game economy.

## Core interaction loop
1. Choose a lesson or a blank sandbox.
2. Drag a host, switch, router, server, access point, firewall, VPN endpoint, etc., into the city.
3. Connect ports and configure hostnames, interfaces, MACs, IPv4/CIDR, gateway and later routes, VLANs, NAT and DNS.
4. Select source/destination, run simulation, visualize packet/event path with explanations.
5. Fix the topology or settings if the simulation fails.
6. Pass a challenge validator and earn progress / XP.

## Metaphors
Subnet = district; router = intersection; switch = neighborhood hub; firewall = checkpoint; VPN = tunnel; packet = moving courier; DNS = address directory; server = service building; NAT = translation checkpoint.

## MVP v0.1
Playable single-page app with responsive toolbar, device palette, isometric canvas, device inspector, simulation event log and a tutorial/challenge panel. Must permit placing 2 PCs + 1 switch, creating two Ethernet links, configuring both PCs with valid IPv4/CIDR and stable autogenerated MACs, sending a simulated packet and seeing successful or failed delivery with useful reasons. Initial guided challenge: connect hosts on the same /24 through a switch and verify communication. Persist a sandbox topology locally; offer reset. Prefer browser-local storage initially.

## Later learning modules
IPv4/CIDR, direct link, ARP, switching, routing/default gateway, DNS/DHCP, NAT, VLANs, VPN, firewall behavior, host discovery and service enumeration concepts. Nmap content is conceptual and fully simulated, not a front end for scanning real machines.

## Non-goals for v0.1
Multiplayer, real network emulation, privileged packet capture, integrations with real routers, a cloud backend, sign-in, AI question generation, payments, mobile app and photorealistic 3D.

## Quality bar
No fake networking validation: if a result is displayed as a simulation, it must come from the configured topology and deterministic engine. If a feature is illustrative only, label it as such.

# Visual identity

**Name:** Subnet City  
**Tagline:** Build the network. Learn the logic.  
**Personality:** Friendly, technical, playful, modular, clear, modern and credible.

## Palette
- Electric Blue `#2F6BFF` (primary actions, connections)
- Deep Navy `#163B7A` (headings)
- Soft Sky `#DCEBFF` (subtle fills)
- Teal `#20B8A8` (valid route)
- Green `#49C46B` (success)
- Amber `#F6B73C` (warning / hints)
- Coral `#F26464` (blocked route / failure)
- Dark Text `#1E2A3A`
- Medium Gray `#7B8794`
- Light Gray `#EEF2F7`
- White `#FFFFFF`

## Typography
Headings: Sora (fallback geometric sans). UI/body: Inter (fallback system sans). Avoid tiny text and rely on high-contrast overlays for network labels.

## 3D/2D style
Bright neutral background, slightly rounded isometric city tiles, low-poly buildings, compact routers/switches, clean orthographic projection, soft ambient shadows, blue connection paths and tiny packet animations. No noisy gaming textures or heavy realism. The `brand/brand-board.png` image supplies visual direction; it is an illustrative brand exploration, not functional UI specs.

## Product layout
Top: Build | Simulate | Learn | Challenge. Left: device library. Center: city builder. Right: selected object inspector. Bottom: structured simulation events and actionable explanations.
